## Technical parts
This bot is written in typescript, uses sapphire for discord and drizzle for db.
There are also some of my handy utils you can use *(just remember about the license lol)*
Also warning that some files may contain comments of me complaining about why x or y is not a thing or smth lmao

# Forking
Make your discord bot on discord developers portal (and get bot token for later)
Open your terminal of choice
Install git (if not present)
Install npm (if not present)
`git clone https://github.com/liirios/EEltreqcBot.git`
move to resulting folder (`cd EEltreqcBot` or smth idk)
`npm install`
make your .env file in ./src/ folder (theres also .env.example, you can just rename it) and put your bot token there
`npm run build`
`npm start`
